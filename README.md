# CampusPulse

面向 Windows 11 的校园网自动认证工具，计划提供可分享的安装包、后台自动重连、可选开机自启动及插电无人值守模式。

**当前状态：Core、后台服务和 WPF 界面已有可构建的预览实现；当前工作区通过 24 项模拟离线检查。针对本机 VPN 虚拟网卡干扰，已修复物理有线路由与绑定 DNS 探测；正式后台的只读检测及用户核对的界面状态均为在线，未提交密码。源码和验收文档已推送并回读公开 GitHub `main`。下一步是在校园门户确实要求登录时手动验收一次认证。最终安装包尚未重新打包；真实账号登录、跨夜恢复及安装生命周期尚未验证。**

**接手项目请先读 [接手指南与项目进度](docs/HANDOFF.md)**，其中列出确定的需求、已有文件、未完成工作、下一步顺序和后续如何更新进度。状态更新时间：2026-09-28。

## 第一版范围

- Windows 11 x64、有线网络；默认门户为 `http://10.62.164.14/`，可填写校内 HTTP IPv4 门户首页。当前只适配与该校相同的 Dr.COM 页面和接口配置，其他地址须通过页面核对后才会提交密码。
- 运营商选择：中国联通、中国移动、中国电信、校内网（无外网）；后者只显示校内网状态，不当作公网恢复。
- 自动等待夜间断网后的恢复，不要求用户知道早上恢复时间。
- 开机自动运行、自动重连、无人值守防睡眠三个独立开关。
- 后台服务与设置窗口分离，窗口关闭后后台可继续工作。
- 每位使用者自行填写账号密码；凭据仅在本机保存，不进入仓库和安装包。
- 成功以公网连通性验证为准，不包含任何远程控制软件测试。

其他学校的不同认证协议尚未适配；四个选项及自填地址目前只通过模拟测试，尚需在对应校园网络实测。

## 开发与发布

计划采用 C#、.NET 10 LTS、WPF、Windows Service 和 Inno Setup。安装包包含运行环境；安装及首版设置窗口需要管理员权限。

`scripts/check-dev.ps1` 于 2026-09-28 对当前代码完成四项目 Release 构建及 24 项进程内模拟测试；只读网络诊断确认物理有线接口，并得到 `internet_verified`，这不等于真实账号登录成功。`scripts/build.ps1` 曾使用 .NET 10.0.203 和 Inno Setup 6.7.3 对旧代码完成自包含发布与安装包编译；该安装包不含本轮功能。安装器静默启动曾停滞；升级卸载和校园网认证尚未验收。

正式后台验收的临时服务副本已按当前代码刷新到已忽略的 `.local/` 下。用户在正式窗口关闭并保存自动重连、移除旧临时后台后，已用保留数据模式重新注册新版临时服务。系统当前回读服务为 Running/延迟自动启动，与已保存的“开机自动运行”一致；自动重连仍关闭。一次正式后台 `check` 只读检测返回在线，用户确认正式窗口显示一致，未执行登录。插电时短暂开启无人值守可观察到系统防睡眠请求，恢复关闭后请求消失；设置窗口进程已退出，后台继续运行。真实认证、跨夜、完整安装生命周期仍未完成。临时界面自包含发布因本地缺少对应运行包而失败，开发构建与 24 项离线测试复查通过。

管理员可用 `scripts/dev-service-validation.ps1 -Action Install` 首次临时注册开发后台；已有受保护数据且确认自动重连已暂停时，可明确使用 `-Action Install -PreserveData` 复用数据。脚本会先检查目录、配置版本和已暂停状态，并按已保存的“开机自动运行”设置启动类型；拒绝覆盖已有同名服务或程序目录。之后用 `-Action Open` 打开**正式**界面；测试结束用 `-Action Remove` 移除测试服务，凭据存在时保留数据。当前新版临时服务正在运行；安装包生命周期仍需在最终打包后单独验收。

**当前开发顺序：先修复并验证功能，最后重新打包。** 日常检查运行 `powershell -File scripts/check-dev.ps1`，只构建源码并运行模拟测试，不生成发布文件或安装包，也不触发真实校园认证。已有的旧预览安装包仅保留为历史本地产物，不作为当前验收入口。

要查看当前窗口，在仓库目录运行 `powershell -File scripts/open-demo.ps1`。它从已构建的 DLL 打开**演示模式**，显示模拟状态，不连接后台或校园网；若提示缺少构建文件，先运行上面的 `check-dev.ps1`。窗口能打开只证明界面可启动，不代表自动认证已经可用。

公开源码仓库：[aaamqrx/CampusPulse](https://github.com/aaamqrx/CampusPulse)。安装包计划在功能与安装生命周期验收后通过 Releases 提供；目前没有已验收的 Release。

`.local/`、`.tools/`、`artifacts/`、实际凭据和本机日志不提交。每次推送前检查暂存内容和提交历史，不能仅依赖忽略规则。
