## 组件契约

- Core：Contracts.cs 定义公共模型；认证与联网探测不存储凭据。
- Service：本地受限控制通道、加密凭据、周期检查、退避重试、防睡眠请求；开机自动运行是独立可选设置。
- App：设置、状态、托盘；不读取已存密码，不直接提交校园认证。
- Installer：包含运行环境，安装/升级/卸载服务，按原配置启用服务；首次安装默认暂停。
- GitHub：公开源码和构建流程；Release 附安装包。实际账号、密码、抓包和本机日志不进入仓库。

## 验收

1. 自动化测试覆盖账号后缀、表单编码、门户识别、错误分类和重试。
2. 无凭据时不认证，非匹配门户不发送密码。
3. 实际安装、升级和卸载，配置与凭据权限核查。
4. 实际登录及跨夜恢复后，验证互联网探测端点内容；用户明确不需要 UU 远程测试。

第 4 项需用户在本机填写凭据，未完成前公开版本持续标为预览版。
