## 1. 用一分钟了解项目

用户的校园有线网每晚 23:30 断开，次日恢复时间未知，恢复后需要访问网页填写账号密码并选择运营商。用户希望留校笔记本无人操作也能恢复互联网连接。

要交付的是一个 Windows 11 软件：可安装、可分享给同学、具有设置窗口与后台服务，支持自动认证、独立的开机自启动选项和可选插电防睡眠。源码公开到 GitHub，安装包发布在 Releases。

**当前是可构建的预览源码，不是已验收产品。** 2026-09-27 当前代码通过 Core/Service/App Release 构建及 16 项模拟离线测试；旧代码曾完成自包含文件发布及 Inno 安装包编译。本轮运营商和自填地址源码已推送并回读[公开 GitHub 仓库](https://github.com/aaamqrx/CampusPulse)。安装器启动测试停滞，未完成产品安装；没有真实登录成功记录，也没有 Release。

用户要求先完成开发文档再实现，文档基线已完成。当前推进 M1 认证与状态机和 M2 后台服务；代码存在不等于系统集成通过。

## 6. 关键设计决定

- 技术栈：C#、.NET 10 LTS、WPF、Windows Service、Inno Setup；首版 Windows 11 x64 自包含发布。
- `StartWithWindows=true`：默认允许后台随开机启动；关闭后改 Manual，不改 Disabled，不立即停止正在运行的服务。
- `Enabled=false`：初次安装不自动认证；配置有效且用户启用后才开始。
- `UnattendedMode=false`：用户主动开启且插电时防空闲睡眠；独立于重连开关，后台停止时释放。
- 只自启后台，不自动弹出管理员托盘；首版设置窗口需要管理员权限。
- “立即检测”不提交密码；“立即重连”按需只尝试一次；停止服务由界面调用系统服务管理器，不能调用已停止服务的管道。
- 服务身份设计为 LocalSystem；DPAPI 机器级加密必须同时有目录/文件权限，管道只允许本机受权管理员和 SYSTEM。
- 用户更换账号、运营商或门户地址必须重新输入密码；旧配置版本的密码不用于新版后缀。单纯留空密码仅在认证身份完全不变时表示保留。
- 自填地址限私有 IPv4 的 HTTP 门户首页；后台仅访问该主机的受支持 Dr.COM 路径和固定公网探测来源，页面、配置及所选模板不匹配时停止在提交密码之前。
- 校内网（无外网）单独显示校内在线状态，不记为公网恢复成功。
- 联网后继续低频检查；两个探测来源、预期内容校验、部分连通状态，不能因单一探测失败反复登录。
- “认证成功”与“公网验证通过”分别记录；界面不依据关键词或 HTTP 200 就显示恢复完成。
- 原项目 NightMode 是主题，不是夜间定时策略；主题和其他学校模板可以后置。

3. **系统集成与设计差距**：模型和界面代码已有预览实现；仍须验证新控件、配置版本迁移、凭据与运营商/门户地址绑定、暂停、检查、重连、服务重启后的错误保护和本机权限是否符合文档。
