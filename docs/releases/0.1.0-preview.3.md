# CampusPulse 0.1.0-preview.3

本预览版增加更新提醒、统一软件图标及自动构建发布工具，校园认证与三个开关的行为沿用已验收版本。

## 变化

- 设置窗口启动时检查一次 GitHub 版本，提供“检查更新”“查看更新”；按数字比较预览版本，由使用者主动安装。
- 程序、窗口、任务栏、托盘、快捷方式和安装包统一使用网络脉冲图标。
- 提交/PR 自动构建与离线检查；预览标签从干净源码打包，先生成草稿。
- 清单记录源提交、SDK、安装包 SHA-256 和 App/Service 载荷文件哈希。
- GitHub 首页按下载、配置、开关、支持范围及反馈整理，历史另行保留。

## 安装和支持范围

Windows 11 x64、有线网、与当前学校相同的 Dr.COM 配置。需要管理员权限，自带运行环境，**未签名**。每位使用者在本机填写门户、运营商及凭据。

升级保留原安装位置和三个开关。退出界面后后台继续，停止后台同时停止重连及防睡眠。
