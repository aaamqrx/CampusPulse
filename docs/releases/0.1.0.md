# CampusPulse 0.1.0

首个正式版，承接 preview.3 的校园有线网自动认证、独立三个开关、托盘界面和更新提醒。用户于 2026-10-13 确认连续使用稳定、基本没有问题；本版认证逻辑和配置格式保持兼容。

## 适用范围

Windows 11 x64、有线校园网，当前已实测本校 Dr.COM 电信。其他符合当前页面模板、认证接口及运营商参数的 Dr.COM 网络可以尝试；仅登录页相似不能证明兼容。每位使用者在本机填写门户与账号密码。

安装包包含运行环境，需要管理员权限，**未签名**。升级保留安装目录、密文凭据及三个开关。正式版更新器只提示后续正式版，预览版可提示本正式版。
