# CampusPulse 0.1.0

首个正式版，承接 preview.3 的校园有线网自动认证、独立三个开关、托盘界面和更新提醒。用户已确认连续使用稳定、基本没有问题。本版认证逻辑和配置格式保持兼容。

## 适用范围

Windows 11 x64、有线校园网，当前已实测本校 Dr.COM 电信。其他符合当前页面模板、认证接口及运营商参数的 Dr.COM 网络可以尝试；仅登录页相似不能证明兼容。每位使用者在本机填写门户与账号密码。

安装包包含运行环境，需要管理员权限，未签名。升级保留安装目录、密文凭据及三个开关。正式版更新器只提示后续正式版，预览版可提示本正式版。

## 验收

当前为发布候选，构建、隔离安装和公开下载结果将在完成后更新。源码清单与 SHA-256 将随实际安装包提供。

## 已知边界

连续稳定性来自用户现场反馈，未推定具体夜数。已有真实认证与自动恢复证据继续有效，本版没有要求重新认证。依用户要求，本机现有 preview.3 保持不动；未在本机安装正式版。干净 Windows 11、其他电脑/DPI、其他学校运营商、卸载后真实重启、完整安装失败组合尚未全面验证；云端 Windows Server 安装结果按实际环境单独记录。未签名状态如实披露，不要求关闭系统安全功能。

反馈请附软件版本、Windows 版本和脱敏事件，不上传账号密码、完整认证请求或抓包。
